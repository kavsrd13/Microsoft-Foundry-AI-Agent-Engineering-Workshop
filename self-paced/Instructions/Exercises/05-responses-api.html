Quickstart: Build agents using the Responses API

In this quickstart, you call the Responses API on a Foundry project endpoint from your own code to build an ephemeral agent — an agent whose definition (instructions, tools, model) lives in your application code instead of as a persisted resource in Foundry Agent Service. Each call constructs the agent in your process and invokes the Responses API for model inference and tool orchestration.

This pattern fits developers, ISVs, and digital natives who want their agent definitions to ship and version with the rest of their application code, rather than as an out-of-band resource that someone has to keep in sync with the app. Unlike prompt agents, there is no agent resource to create, update, or delete in Foundry — lifecycle management is replaced by calling the Responses API directly.

This exercise takes approximately 60 minutes.

Note: The recommended path is the Agent Framework (agent-framework-foundry), which handles authentication, tool wiring, and message orchestration for you using FoundryChatClient.

Before you start

What you will do

  • Understand the ephemeral agent pattern and when to use in-process vs hosted agents.
  • Install the agent-framework-foundry package and set up environment variables.
  • Create an ephemeral agent using FoundryChatClient and Agent.
  • Define local Python function tools using the @tool decorator and let the agent invoke them.
  • Add hosted platform tools like web search via FoundryChatClient.get_web_search_tool().
  • Stream responses token by token as they generate.

Prerequisites

  • Python 3.10 or later installed.
  • The Azure CLI installed and signed in (az login).
  • A model deployed in your Microsoft Foundry project (e.g. gpt-4o-mini or gpt-4o).
  • Your Foundry project endpoint URL and deployed model name.

Task 2: Create an ephemeral agent

Create an ephemeral agent that runs locally in your process and calls the Responses API for model inference and tool orchestration.

  1. Create a file called 01_ephemeral_agent.py:

    New-Item 01_ephemeral_agent.py -ItemType File

  2. Add the following code (exact code from Microsoft Learn):

    import asyncio
import os

from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential

async def main() -> None:
    agent = Agent(
        client=FoundryChatClient(
            project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
            model=os.environ["FOUNDRY_MODEL"],
            credential=AzureCliCredential(),
        ),
        instructions="You are a helpful assistant.",
    )

    result = await agent.run("What is the capital of France?")
    print(f"Agent: {result}")

if __name__ == "__main__":
    asyncio.run(main())

  3. Code explanation:

    • FoundryChatClient: Connects to the Foundry project endpoint ({project_endpoint}/openai/v1/responses) and uses Entra ID authentication via AzureCliCredential.
    • Agent(...): Instantiates an in-process agent with instructions and model client.
    • agent.run(...): Sends the user prompt to the Responses API and awaits the natural language reply.
    • Lifecycle: Because this agent is ephemeral, no definition is saved or stored in Azure — the agent lives and terminates with the Python process.

  4. Run the script:

    python 01_ephemeral_agent.py

    Check: The output prints the agent's response: Agent: The capital of France is Paris.

Task 3: Add function tools

Define local function tools and pass them to the agent. The agent automatically calls these tools when needed during a conversation.

  1. Create a file called 02_function_tool.py:

    New-Item 02_function_tool.py -ItemType File

  2. Add the following code (exact code from Microsoft Learn):

    import asyncio
import os
from random import randint
from typing import Annotated

from agent_framework import Agent, tool
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential
from pydantic import Field

@tool(approval_mode="never_require")
def get_weather(
    location: Annotated[str, Field(description="The location to get the weather for.")],
) -> str:
    """Get the weather for a given location."""
    conditions = ["sunny", "cloudy", "rainy", "stormy"]
    return f"The weather in {location} is {conditions[randint(0, 3)]} with a high of {randint(10, 30)}°C."

async def main() -> None:
    agent = Agent(
        client=FoundryChatClient(
            project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
            model=os.environ["FOUNDRY_MODEL"],
            credential=AzureCliCredential(),
        ),
        instructions="You are a helpful weather agent.",
        tools=get_weather,
    )

    result = await agent.run("What's the weather like in Seattle?")
    print(f"Agent: {result}")

if __name__ == "__main__":
    asyncio.run(main())

  3. Code explanation:

    • @tool(approval_mode="never_require"): Registers a Python function as a tool callable by the agent. The docstring and Field(description=...) describe the tool's purpose and schema to the model.
    • tools=get_weather: Provides the tool to the agent. When the agent receives a prompt asking for weather, the Responses API generates a tool call, the local Python function executes in-process, and the result is returned to the model to formulate the final answer.

  4. Run the script:

    python 02_function_tool.py

    Check: The agent automatically calls get_weather for "Seattle" and replies in natural language with the generated temperature and condition.

Task 4: Use the web search tool

The Responses API on the Foundry project endpoint provides built-in hosted tools like web search. Give your agent access to web search without writing any local search implementation.

  1. Create a file called 03_web_search_tool.py:

    New-Item 03_web_search_tool.py -ItemType File

  2. Add the following code (exact code from Microsoft Learn):

    import asyncio
import os

from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential

async def main() -> None:
    agent = Agent(
        client=FoundryChatClient(
            project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
            model=os.environ["FOUNDRY_MODEL"],
            credential=AzureCliCredential(),
        ),
        instructions="You are a research assistant. Use web search to find current information.",
        tools=[
            FoundryChatClient.get_web_search_tool(),
        ],
    )

    result = await agent.run("What are the latest updates to Microsoft Foundry?")
    print(f"Agent: {result}")

if __name__ == "__main__":
    asyncio.run(main())

  3. Combining tools: You can also combine hosted tools and local functions in a single agent:

    agent = Agent(
    client=FoundryChatClient(
        project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
        model=os.environ["FOUNDRY_MODEL"],
        credential=AzureCliCredential(),
    ),
    instructions="You are a helpful assistant with web and weather capabilities.",
    tools=[
        FoundryChatClient.get_web_search_tool(),
        get_weather,  # Local function tool defined with @tool
    ],
)

  4. Run the script:

    python 03_web_search_tool.py

    Check: The agent searches the web server-side via the Foundry project endpoint and returns recent information about Microsoft Foundry.

Task 5: Stream responses

Receive responses as they generate instead of waiting for the full completion.

  1. Create a file called 04_stream_responses.py:

    New-Item 04_stream_responses.py -ItemType File

  2. Add the following code (exact code from Microsoft Learn):

    import asyncio
import os

from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential

async def main() -> None:
    agent = Agent(
        client=FoundryChatClient(
            project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
            model=os.environ["FOUNDRY_MODEL"],
            credential=AzureCliCredential(),
        ),
        instructions="You are a helpful assistant.",
    )

    print("Agent: ", end="", flush=True)
    async for chunk in agent.run("Tell me a fun fact.", stream=True):
        if chunk.text:
            print(chunk.text, end="", flush=True)
    print()

if __name__ == "__main__":
    asyncio.run(main())

  3. Code explanation: Setting stream=True returns an asynchronous generator yielding delta chunks. Printing each chunk.text as it arrives gives users immediate, responsive feedback.

  4. Run the streaming script:

    python 04_stream_responses.py

    Check: Words appear smoothly in real time across the terminal until the sentence completes.

Task 6: Observability and enterprise capabilities

Ephemeral does not mean unmanaged. Because calls route through the Foundry project endpoint:

  • Tracing and telemetry: Requests, token counts, and tool executions flow automatically into Azure Application Insights.
  • Content filters & RAI: Project-level responsible AI policies and content filters apply to every prompt and response.
  • On-Behalf-Of (OBO) auth: Tools can execute downstream queries as the authenticated caller.

Knowledge check

Answer each question, then expand it to check yourself.

1. What is the key difference between a prompt agent and an ephemeral agent?
  • A. Ephemeral agents do not support models from the catalog
  • B. Ephemeral agents exist only in application code and require no Azure resource lifecycle management
  • C. Prompt agents cannot use tools

Answer: B

Ephemeral agents ship and version directly with your codebase, avoiding the need to create, update, or delete cloud agent resources.

2. Which class in agent_framework.foundry connects your agent to the Foundry Responses API?
  • A. FoundryChatClient
  • B. OpenAIHttpClient
  • C. AzureAgentSession

Answer: A

FoundryChatClient binds to your project endpoint and handles authentication, tool wiring, and Responses API calls.

3. How do you stream tokens incrementally with the Agent Framework?
  • A. Call agent.poll() in a while loop
  • B. Pass stream=True to agent.run() and iterate over chunks with async for
  • C. Use websockets directly

Answer: B

Passing stream=True yields incremental text deltas as an async generator.
