# Illustrative fallback — NOT a captured service result

Question: What leave and travel rules apply to an Acme employee?

Teaching flow: knowledge base → selected source → matching policy passages → references. In the GA path, participants inspect extractive evidence. In preview, a model may plan multiple queries and synthesise an answer.

Open the local synthetic PDFs and ask participants to identify one passage from each policy and record its filename and page. Do not invent numeric entitlements or service trace IDs. This exercise explains retrieval; it does not validate Foundry IQ.

The instructor should rehearse `retrieve.py` and save `live-retrieval.json` with date, region, API version and deployment type before describing any output as captured.
