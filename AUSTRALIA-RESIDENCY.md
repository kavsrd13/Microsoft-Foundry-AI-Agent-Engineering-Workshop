# Australian residency and service verification

Australia East supports Foundry project resources. Verify model, tool, evaluator and hosting availability individually. Model processing geography depends on deployment type (Global / Data Zone / Regional) and model/service terms, not merely the region printed on the Foundry account. A Global deployment in an Australia East project does not establish Australian-only processing.

| Check | Evidence to record before class |
|---|---|
| Project and supporting storage | Account/project resource location; actual Storage/Search/Cosmos locations |
| Model inference | Model/version, deployment name, type, offered region/zone and service terms |
| Embeddings | Separate embedding model deployment type/location and Search connection |
| Document Intelligence | Region, GA API version2024-11-30 and network path |
| IQ and knowledge sources | Retrieval/planning/synthesis status separately; source storage and downstream endpoints |
| MCP | Endpoint operator, read operations, submitted arguments, approval and external data boundary |
| Evaluation | Judge model geography plus managed safety evaluator availability/data-processing terms |
| Tracing | App Insights workspace geography, retention, access and content capture settings |
| Hosting | Runtime region, image registry, identity, connected tools and model deployment geography |

Synthetic data makes teaching safer but does not replace an organisation's deployment review. Do not silently switch to Sweden Central or East US2 if Australia East quota is unavailable. Record approval or use a local/illustrative demonstration. Data Zone availability does not imply that an Australian zone exists.

Read [deployment types](https://learn.microsoft.com/azure/ai-foundry/openai/how-to/deployment-types), [Foundry region support](https://learn.microsoft.com/azure/foundry/reference/region-support), [standard agent setup](https://learn.microsoft.com/azure/foundry/agents/concepts/standard-agent-setup) and each lab's primary source. Availability changes; use the tenant portal and current service documentation for the delivery date.
