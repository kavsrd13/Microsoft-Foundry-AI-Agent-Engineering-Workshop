Quickstart: Create a prompt agent

In this quickstart, you create a prompt agent in Microsoft Foundry Agent Service and have a conversation with it. A prompt agent is a declaratively defined agent that combines a model from the Foundry model catalog, instructions, tools, and natural language prompts to drive behavior.

Unlike ephemeral agents that exist only in memory during your code execution, a prompt agent is persisted as a named resource in your Foundry project with full versioning.

This exercise takes approximately 45 minutes.

Note: This code uses Azure AI Projects 2.x (the Foundry projects new API) and is incompatible with Azure AI Projects 1.x.

Lab folder: labs/04-prompt-agent
Run scripts from: the lab folder
Environment: azure-ai-projects>=2.3.0, azure-identity, python-dotenv

Before you start

What you will do

  • Set up an isolated virtual environment and install the required Azure AI Projects packages.
  • Authenticate using az login and Azure Entra credentials with DefaultAzureCredential.
  • Define and create a prompt agent resource in your Foundry project using PromptAgentDefinition.
  • Connect to your agent using the OpenAI-compatible Responses API client.
  • Create a multi-turn conversation session and chat with the agent, verifying context retention.

Prerequisites

  • Python 3.10 or later installed (Python 3.11 recommended).
  • The Azure CLI installed and signed in (az login).
  • A model deployed in your Microsoft Foundry project (e.g. gpt-4o-mini or gpt-4o).
  • Your Foundry project endpoint URL, formatted as: https://<resource-name>.services.ai.azure.com/api/projects/<project-name>.

Task 1: Set up

Begin by creating an isolated virtual environment and installing the required packages.

  1. Open a PowerShell terminal and navigate to the lab folder:

    cd labs/04-prompt-agent

  2. Create a Python virtual environment:

  3. Activate the virtual environment:

    Check: Your terminal prompt should now be prefixed with (.venv).

  4. Install the required packages. Note the pinned version of azure-ai-projects:

    pip install "azure-ai-projects>=2.3.0" azure-identity python-dotenv

  5. Sign in using the Azure CLI to authenticate before running your Python scripts:

    Note: DefaultAzureCredential automatically picks up your active Azure CLI login session, so no API keys or passwords are stored in code.

Task 2: Create a prompt agent

Now create a prompt agent using your deployed model. The agent uses a PromptAgentDefinition with instructions that define the agent's behavior. You can update or delete agents anytime.

  1. Create a file called create_agent.py in labs/04-prompt-agent:

    New-Item create_agent.py -ItemType File

  2. Add the following code to create_agent.py (exact code from Microsoft Learn):

    from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient
from azure.ai.projects.models import PromptAgentDefinition

# Format: "https://resource_name.services.ai.azure.com/api/projects/project_name"
FOUNDRY_PROJECT_ENDPOINT = "your_project_endpoint"
FOUNDRY_AGENT_NAME = "your-agent-name"

# Create project client to call Foundry API
project = AIProjectClient(
    endpoint=FOUNDRY_PROJECT_ENDPOINT,
    credential=DefaultAzureCredential(),
)

# Create an agent with a model and instructions
agent = project.agents.create_version(
    agent_name=FOUNDRY_AGENT_NAME,
    definition=PromptAgentDefinition(
        model="gpt-5-mini",  # supports all Foundry direct models
        instructions="You are a helpful assistant that answers general questions",
    ),
)
print(f"Agent created (id: {agent.id}, name: {agent.name}, version: {agent.version})")

  3. Code explanation:

    • AIProjectClient: The root client that communicates with your Foundry project endpoint using Entra credentials.
    • PromptAgentDefinition: The declarative blueprint for the agent, defining which foundation model to use and its system instructions.
    • project.agents.create_version(...): Creates or publishes a versioned prompt agent in Foundry Agent Service. If the agent does not yet exist, version 1 is created. Subsequent calls publish new immutable versions.

  4. Update FOUNDRY_PROJECT_ENDPOINT with your actual Foundry project endpoint, FOUNDRY_AGENT_NAME with your desired agent name (such as "MyPromptAgent"), and model with your deployed model name (such as "gpt-4o-mini").

  5. Run the script to create your agent:

    python create_agent.py

    Check: The output confirms the agent was created and prints the agent ID, name, and version number to the console, for example:
    Agent created (id: agent_abc123, name: MyPromptAgent, version: 1)

Task 3: Chat with the agent

Use the agent you created to interact by asking a question and a related follow-up. The conversation maintains history across these interactions.

  1. Create a second file called chat_with_agent.py in labs/04-prompt-agent:

    New-Item chat_with_agent.py -ItemType File

  2. Add the following code to chat_with_agent.py (exact code from Microsoft Learn):

    from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient

# Format: "https://resource_name.services.ai.azure.com/api/projects/project_name"
FOUNDRY_PROJECT_ENDPOINT = "your_project_endpoint"
FOUNDRY_AGENT_NAME = "your_agent_name"

# Create project and openai clients to call Foundry API
project = AIProjectClient(
    endpoint=FOUNDRY_PROJECT_ENDPOINT,
    credential=DefaultAzureCredential(),
)
# Get an OpenAI client pre-bound to the specified agent
openai = project.get_openai_client(agent_name=FOUNDRY_AGENT_NAME)

# Create a conversation for multi-turn chat
conversation = openai.conversations.create()

# Chat with the agent to answer questions
response = openai.responses.create(
    conversation=conversation.id,
    input="What is the size of France in square miles?",
)
print(response.output_text)

# Ask a follow-up question in the same conversation
response = openai.responses.create(
    conversation=conversation.id,
    input="And what is the capital city?",
)
print(response.output_text)

  3. Code explanation:

    • project.get_openai_client(agent_name=FOUNDRY_AGENT_NAME): Obtains an OpenAI-compatible client pre-configured to route requests through your Foundry project and bound to your specific agent definition.
    • openai.conversations.create(): Allocates a server-side conversation session. This manages message state and history automatically.
    • openai.responses.create(conversation=..., input=...): Invokes the Responses API. Passing conversation.id ensures that previous turns are included in the prompt context.
    • The follow-up prompt ("And what is the capital city?") does not mention "France", but the agent correctly answers Paris because conversation history is preserved.

  4. Update the placeholders with your project endpoint and agent name, then run the chat script:

    python chat_with_agent.py

    Check: You see the agent's responses to both prompts. The follow-up response demonstrates that the agent maintains conversation history across turns.

Knowledge check

Answer each question, then expand it to check yourself.

1. Where does the definition of a prompt agent live?
  • A. Only in local memory in the Python script
  • B. As a versioned resource in the Foundry project
  • C. In an Azure Blob storage account only

Answer: B

Prompt agents are declaratively defined and persisted as resources within your Foundry project, allowing multiple applications and versions to share the same agent.

2. How does the agent maintain state between turns when using the Responses API?
  • A. The client must re-send the entire message list each turn
  • B. By passing the `conversation.id` created via `openai.conversations.create()`
  • C. State is saved automatically in local cookies

Answer: B

Passing the `conversation.id` links turns together so Foundry Agent Service can manage and inject prior conversation context.

3. Which SDK class defines the agent's model and instructions?
  • A. `PromptAgentDefinition`
  • B. `ChatCompletionsOptions`
  • C. `AgentConfig`

Answer: A

In Azure AI Projects 2.x, `PromptAgentDefinition` encapsulates the model name, instructions, and tools for the agent.

Summary

In this quickstart, you created a prompt agent in Microsoft Foundry Agent Service and interacted with it across multiple turns:

  • Created a versioned prompt agent using project.agents.create_version() and PromptAgentDefinition.
  • Acquired an agent-scoped OpenAI Responses API client via project.get_openai_client().
  • Created a conversation session with openai.conversations.create().
  • Conducted a multi-turn dialogue, proving server-side context retention across turns.
